# 押题库格式约定

本目录按一级子目录划分两个题库，每个 `.md` 文件对应一个「预测押题」学习主题。`make dev` 启动预览服务后，
面板会自动递归读取子目录（每次请求重读，改完刷新浏览器即生效）：

| 目录 | 归属 | 挂载方式 |
| --- | --- | --- |
| `project/` | 项目经历 | `matchName` 命中项目条目标题，标题右侧出「押题」按钮 |
| `skill/` | 专业技能 | `keywords` 命中技能区关键词词条，词条整块可点（无按钮）直接展开抽屉 |
| `answers/` | 外置解答 | 不参与扫描，题包用 `@answer:` 引用 |

## 文件格式

```markdown
---
matchName: 政务 RAG 知识库系统   # 【项目题包】简历项目 displayName 的子串，用于把主题挂到项目上
keywords: 混合检索 | 重排序      # 【技能题包】技能关键词词条的子串，| 分隔，挂到专业技能区词条上（可省略）
title: 政务 RAG 知识库系统         # 抽屉标题（必填，缺失则整个文件被跳过）
stack: Python | FastAPI          # 技术栈一行，展示在标题下方（可省略）
---

## 预测押题

- 问题一？
  参考解答（缩进书写，接在题目行下方，可多行；dev 面板里点击题目可展开）。
- 问题二？

## 项目亮点挖掘

1. **亮点标题**
   亮点描述（可多行，缩进行会并入同一条描述）。
```

## 匹配规则

- `project/` 题包：`matchName` 命中「项目经历 / 个人项目」条目标题时，标题右侧出现「押题」按钮；
- `skill/` 题包：`keywords` 任一子串命中技能词条时，该词条整块可点（带虚线下划线，
  不挂任何「押题/诊断报告」按钮），直接展开抽屉（列表头部显示「技能押题」），
  题目详情/内嵌演示交互与项目押题完全一致；同词条命中多个题包时连点循环切换；
- 未命中任何条目时不展示入口，仅在浏览器控制台告警（补准 matchName / keywords 即可挂上）；
- 一个项目/词条可以挂多个主题（多个文件的 `matchName` 或 `keywords` 写同一个子串即可）。

## 其他说明

- 「已掌握」勾选进度存浏览器 localStorage（key 为文件名），刷新/重启不丢；
- 有解答的题目点击可展开/收起参考解答，无解答的题目置灰不可点；
- 面板随 dev 预览与 `make build` 产出的 HTML 一起注入（构建期内联数据），PDF 与打印版面不含任何面板痕迹。
