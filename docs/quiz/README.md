# 押题库格式约定

本目录下的每个 `.md` 文件对应一个「预测押题」学习主题。`make dev` 启动预览服务后，
面板会自动读取本目录（每次请求重读，改完刷新浏览器即生效）。

## 文件格式

```markdown
---
matchName: 政务 RAG 知识库系统   # 简历项目 displayName 的子串，用于把主题挂到项目上
title: 政务 RAG 知识库系统         # 抽屉标题（必填，缺失则整个文件被跳过）
stack: Python | FastAPI          # 技术栈一行，展示在标题下方（可省略）
---

## 预测押题

- 问题一？
  参考解答（缩进书写，接在题目行下方，可多行；dev 面板里点击题目可展开）。
- 问题二？

## 项目亮点挖掘

1. **亮点标题**
   亮点描述（可多行，缩进行会并入同一条描述）。
```

## 匹配规则

- `matchName` 命中「项目经历 / 个人项目」条目标题时，标题右侧出现「押题」按钮；
- 未命中任何项目时不展示入口，仅在浏览器控制台告警（补准 matchName 即可挂上）；
- 一个项目可以挂多个主题（多个文件的 `matchName` 写同一个子串即可）。

## 其他说明

- 「已掌握」勾选进度存浏览器 localStorage（key 为文件名），刷新/重启不丢；
- 有解答的题目点击可展开/收起参考解答，无解答的题目置灰不可点；
- 面板仅存在于 dev 预览响应中，`make build` 产出的 HTML 与 PDF 不含任何面板痕迹。
