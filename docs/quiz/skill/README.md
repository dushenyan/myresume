# 专业技能题包目录

本目录下的每个 `.md` 文件对应一个「技能主题」学习单元，格式与
[`../project/`](../project/) 完全一致（见 [上层 README](../README.md)），
区别只在挂载方式：

- front-matter 不写 `matchName`，改写 `keywords`：简历「专业技能」区
  关键词词条的**子串**，`|` 分隔，如 `keywords: Transformer | 位置编码`；
- 命中后该词条整块可点（带虚线下划线，不挂任何「押题/诊断报告」按钮），
  直接点击展开抽屉（列表头部显示「技能押题」）；
- 一个题包可以命中多个词条（所有命中的词条都可点，打开同一题包）；
  一个词条被多个题包命中时，连点会循环切换题包。

新技能主题直接在本目录建 `<主题名>.md` 即可，外置解答仍统一放 `../answers/`。
