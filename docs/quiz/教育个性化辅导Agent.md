## 预测押题

- 学生能力画像怎么建模？冷启动怎么办？为什么用掌握度向量而不是 IRT/BKT？
  知识点×掌握度向量（0~1），每个知识点一个分数。冷启动无答题记录时给先验 0.5（中性假设）。IRT/BKT 统计上更严谨但需要大量样本参数标定，教学场景初期数据稀疏且需要可解释性（「分数低=没掌握」老师秒懂），掌握度向量简单透明可运营，数据量上来后可升级 BKT。
- 掌握度为什么用指数平滑更新？α 怎么选？单题失误会不会把画像打崩？
  新证据 = 0/1 的极端值，直接赋值会让画像随单次表现剧烈震荡；指数平滑 master = (1-α)·master + α·score，α=0.3 让单题只移动 30% 步长，连续表现才会推动趋势。单题失误最多拉 0.15，打不崩画像。
- 画像数据如何持久化与回溯？答题流水和画像的关系是什么？
  答题流水是事实源（append-only），画像是流水的投影（每次答题后增量更新）。持久化三本账：掌握度当前值、答题数、正确数；回溯时用流水重放可重建任意时点画像，画像存错也能从流水恢复。
- 如何防止辅导系统直接给出答案？Prompt 约束之外还有哪些工程手段？
  三层：Prompt 层显式禁令 + 输出形态约束为提问句；信息隔离层——标准答案根本不传给引导 Prompt（模型想泄也没数据）；后置检测层扫描回复是否含最终答案数值，命中则重新生成。约束不靠模型自觉，靠信息不对称。
- 苏格拉底式引导和普通讲解的教学差异是什么？如何评估引导质量？
  讲解把认知负担外包给系统（学生被动听懂），引导用递进问题让学生自己推出结论（留存率高、可迁移）。评估：引导后独立重做正确率（真懂没有）、引导轮次收敛速度、追问是否针对错因（人工抽检 + 学生评分）——不看「说得顺」看「学没学会」。
- 错因归因（概念不清/粗心/方法错误）怎么判？归因错了会有什么后果？
  规则信号优先：选到概念混淆干扰项→概念不清；正确知识点相关题都对仅本题错且耗时短→粗心；中间步骤对最后方法卡断→方法错误；信号不足才让模型判并给置信度。归因错的后果是练错方向（粗心被当概念不清去重学），所以引导策略设计成前两轮可据新答题信号改判。
- 题目难度如何动态调整？为什么选"连对升、答错降"而不是更复杂的算法？
  连对 2 题升一档、答错降一档（保底 L1），目标把学生维持在「跳一跳够得着」的最近发展区。复杂算法（如知识追踪+强化学习选题）需要大量数据才能体现优势，冷启动期反而不可解释不可控；简单规则先用，数据量上来再升级。
- 难度调整和掌握度更新会不会互相打架（降档后做简单题把掌握度虚高）？
  会，所以掌握度更新按题目难度加权：L1 答对增量小、L3 答对增量大，降档后刷简单题刷不出高分；同时高置信度正确（低档连对）会加速升档，两机制方向上互锁，方向上一个降一个升不会正反馈死循环。
- 如何防止学生刷简单题"混"掌握度？已出题去重和题库耗尽怎么处理？
  防刷：难度加权更新（混分无效）+ 超纲验证（低档连对多时抽一道高档题验真）。去重：已出题 id 按学生维度记录，短期内不出重复；题库耗尽按「薄弱知识点优先 + 难度就近回退」降级选题，并提示运营补题。
- 这套系统如何扩展到新学科（如英语/物理）？题库、归因、难度策略分别要做哪些适配？
  架构层零改动（画像/难度/引导都是学科无关的抽象）；要适配的是配置与语料：题库按「知识点×难度×考查技能」三元组格式新建，归因规则按学科错因体系重写（物理的受力分析错误 vs 数学的通分错误），引导 Prompt 换学科话术模板——引擎复用、学科插件化。

## 项目亮点挖掘

1. **学生能力画像模型**
   知识点掌握度向量 + 冷启动先验 0.5 + 指数平滑更新（α=0.3），单题失误打不崩画像。
2. **苏格拉底式引导防答案泄漏**
   Prompt 层显式禁令 + 输出形态约束为提问句 + 信息隔离（标准答案不传给引导 Prompt）。
3. **动态难度调整落在"最近发展区"**
   连对 2 题升档、答错降档（保底 L1），薄弱知识点优先选题。
4. **错因三类归因**
   概念不清/粗心失误/方法错误，给出针对性练习路径（如"先练 3 道通分专项再回分数加法"）。
5. **画像可解释可运营**
   掌握度、答题数、正确数三本账，薄弱知识点自动排序输出。
6. **题库结构化设计**
   知识点 × L1-L3 难度 × 考查技能三元组建模，全链路离线可运行。
