## 项目亮点挖掘

1. **融合检索双路召回**
   Script Score / RRF 融合 BM25 与 dense_vector 语义检索，Sentence-Transformers 本地化推理，P99 < 200ms、Top-5 命中率 92%。
2. **7 类差异化缓存体系**
   类目树/FAQ 详情/答案视角/搜索结果/渠道配置/热门 FAQ/导航目录，5 分钟～24 小时差异化 TTL + 写操作主动失效，解决知识一致性。
3. **双环境可回滚发布**
   env 字段隔离 + original_id 溯源，测试环境配置、一键同步、正式生效，知识上线前可验证可回滚。
4. **多视角答案适配引擎**
   同一问题按微信/App/Web 渠道差异化下发文本、富文本与交互卡片，新渠道接入不改动问答核心链路。
5. **全异步高吞吐工程**
   FastAPI 全异步链路 + SSE 流式打字机交互，SQLAlchemy 2.0 批量优化支撑 5 万级导出与 3000 条异步批量导入。
6. **性能与一致性论证链**
   单分片规避归并开销、RRF 规避量纲不可比、本地推理规避网络往返——每项指标背后有可讲的调优因果，而非参数玄学。
