### 6.2 第一轮：项目深挖（每项目 3-5 问）

#### 围绕 depth-research-assistant

1. 你的"四角色 Agent + 编排器不调 LLM"是怎么设计的？为什么不让编排器直接调 LLM？
   - 期望回答：可测试、可复现；控制流用纯 Python 写，单元测试不依赖 LLM；语言任务下沉到 Agent
2. JudgeAgent 怎么判断"信息足够"？prompt 里给了哪些维度？
   - 期望回答：覆盖度、来源多样性、新近性等维度；prompt 给出 JSON schema + format_instructions 自约束
3. max_rounds 上限怎么定的？超了怎么办？
   - 期望回答：默认 3 轮；超限即收敛到当前草稿
4. 搜索 API 失败/限流怎么兜底？
   - 期望回答：单次检索失败返回空结果，不中断整体流程（容错设计）
5. 置信度怎么算？依据什么？
   - 期望回答：基于来源时间分布确定性计算；无来源结论显式标注为"模型推断"

#### 围绕 government-advanced-rag

1. 为什么要做三存储架构（MySQL/ES/Neo4j）？每类存储的查询特征是什么？
   - 期望回答：MySQL 存元数据、ES 存全文+向量、Neo4j 承载实体关系（多跳问答）
2. 什么场景必须上 Rerank，什么场景可以只做混合检索？
   - 期望回答：专业库/客服等高精度场景强制走精排；通用对话场景仅混合检索控制延迟
3. 为什么 embedding/rerank 模型用模块级全局单例？
   - 期望回答：模型几 GB 权重 + GPU 初始化耗时大，启动加载一次复用
4. chunk 大小和 overlap 怎么定的？做过对比吗？
   - 待补数据：可坦诚未系统对比
5. Neo4j 现在落地了吗？还是 TODO？
   - 待补数据：可坦诚 TODO，要么补完要么简历去掉

#### 围绕 faq-text-matching

1. 混合检索怎么融合 BM25 分数和向量相似度分数？
   - 期望回答：RRF 倒数排名融合 / 加权归一化
2. 双环境同步时数据冲突怎么处理？
   - 期望回答：env 字段隔离 + original_id 溯源，正式记录指向来源测试记录
3. 缓存和数据库一致性怎么保证？
   - 期望回答：写时主动失效（@invalidate_cache 装饰器）+ TTL 兜底
